# Model-free durable native UI-task observation — bounded profile v1

This source profile extends the existing PanSphaira model-free native task
path. It is not whole original592, B26, M1, broad concurrent native backend
writers, audio, model inference, production activation or a runnable release.
Original540/546/548 and broader592 criteria retain their original boundaries.

## Provider and direct consumer

The containing immutable source binds these counterparts together:

- Existing PAN548 `native-ui-task-projection-v2.mjs` and signed
  `native-context-journal-v1.mjs` own task identity, revisions and events.
- Existing PAN529 `demo/runtime/atomic-resource-budget.mjs` owns the SAME
  `resource-budget.sqlite` connection and reservation/usage truth. No new task
  database, general durable/budget engine or alternate signer is introduced.
- Existing PAN548 model-free invocation executor consumes PAN546's actual
  preview validator or PAN597's actual native document-acceptance proof.
- Existing protected PAN527 sessions authenticate tenant, subject, role,
  instance and generation. Existing context/surface/lease and argument/policy
  guards still precede effects. A copied connection, role or digest is no grant.
- The existing browser invocation panel consumes the typed native observation
  contract. Needed DUI-14 provider/consumer capability is qualified here; whole
 540 or546 CLOSED is not a prerequisite and is not claimed.

Profile versions are `workspace-invocation/effect-command/v2`,
`workspace-ui-task/budget-binding/v1`, `workspace-ui-task/observe/v1` and
`workspace-ui-task/observation/v1`, with their `pansphaira.` schema prefixes.
The exact containing commit/tree, all component byte pins and real direct
positive/negative observations are bound by the delivery evidence. Earlier
qualified releases and legacy task/event/proof bytes are not rewritten.

## Independent read is not writer replacement

`createNativeWorkspaceUiTaskReadbackV2({sessions, root})` opens an existing
owner-private PAN529 file read-only/query-only. It does not initialize storage,
advance `workspace_ui_task_settings_v2.boot_epoch`, attach as a task writer,
create source events, sign a completion, reserve, release or retry anything.
Its closed read takes an authenticated header set plus schemaVersion,
commandId and expectedWriterEpoch. Missing/foreign identities, bindings,
epochs, task IDs, links and result/usage conflicts fail closed.

The original task-writer constructor remains an explicit writer replacement:
it advances the leading boot epoch and retires the prior writer. Real process
exit/restart qualification below uses authorized QUIESCENT owner replacement,
not a concurrent read constructor masquerading as a second writer. Observation
is a distinct capability and cannot attach as the existing write owner.

## One task and native reservation, atomic UNKNOWN custody

New model-free invocation intent uses a versioned original command containing
its immutable budget binding. In one existing PAN529 owner transaction it
reserves zero model units and one runtime COUNT unit, marks UNKNOWN_USAGE,
persists the PAN548 task and appends its signed intent. All or none commit.
Exhaustion and native errors cannot leave a new unbudgeted dispatched task.
Tenant/subject/task/principal and original request bytes bind the reservation.

Completion consumes one runtime COUNT unit, zero model units, only while the
current owner and genuine native target proof remain valid. Task result,
completion event and PAN529 authenticated settlement commit on the same native
connection/transaction. COUNT is not currency or measured model-provider cost.
No real model/provider/audio call is made or authorized by this profile.

A real process can die after native completion but before its response is
delivered. Read the original task/reservation after restart; never create a
replacement effect key or reconstruct an executable in-memory admission.
An interrupted attempted effect without sufficient native proof remains
OUTCOME_UNCONFIRMED/UNKNOWN_USAGE with the full reservation held. Read-only
polling, restart, caller declarations and a model answer do not settle it.

Native owner-only `reconcileUnknown` on the existing executor connection is
not an HTTP operation, retry, cancel or resume. It requires the same authenticated
principal, exact task revision/current writer epoch and independently verified
signed PAN597 proof for the original target/arguments. It can reconcile only
historical native document ACCEPTANCE and its observed runtime use, without
redispatching or claiming current DOM render. An in-memory preview without
surviving native proof remains UNKNOWN. Legacy tasks without a budget link
report usage UNAVAILABLE; old data is not backfilled into invented acceptance.

## Connected browser behavior and scope of evidence

The actual existing panel keeps the original task ID before dispatch and
provides an explicit task-ID read field. Enter in this field invokes READ only,
not the effect form. An eligible effect target/clean preview is not required
for observation; current authenticated source capability and server scope
remain mandatory. Native task/usage, writer epoch, COUNT units and UNKNOWN
custody are displayed separately from DOM, personal save, Undo and business
state. Cancel/resume stay unavailable. A reloaded user may enter the original
ID; an ID itself grants nothing and no automatic effect retry is added.

The fixed entry is `npm run pan592:test`. It includes real separate OS-process
reads, confirmed exit, lost response plus SIGKILL/restart, UNKNOWN holds,
native proof reconciliation/denials and direct typed-consumer mutations.
Connected cases exercise real browser → backend → separately opened persisted
native target, desktop/390px, keyboard/focus, CSS layout zoom, lost response,
explicit read after owner replacement and actual native failure/denied states.
The UNKNOWN UI case uses an exclusively owned synthetic SQLite completion
fault; that fault is not production code, a mocked response or a SIGKILL claim.
Real SIGKILL/restart is separately executed by the process cases. Source-bound
screenshots must actually be inspected. CSS layout zoom is not physical-device
or native browser zoom qualification.

The fixed runner preserves its closed argument/startup/filter/skip boundary,
existing registered prerequisites and same-instance owned short Chromium
scratch. Ordinary dependency reuse is not a fresh installation claim.

## Residuals and limits

- No whole592/B26/M1, broad multi-tenant/task/surface/audio load or process-wide
  crash-durable Exactly-once claim. A confirmed task/usage is not a resurrected
  preview handle, renewed lease or proof that a physical screen was seen.
- Competing additional live profile/Setup writers remain outside this profile.
  A synthetic attempted composite worker opening those unrelated writers while
  the active browser polled was rejected by native BTH fencing; that denial is
  retained, not bypassed or called product acceptance. Only the independent
  read capability and explicitly quiescent native owner replacement are claimed.
- Original broader requirements remain open. No native model cancel/resume,
  product model/audio/cloud grant, operational data/permission, account, expired
  LAN/source/invitation/rollback renewal or cutover is introduced.
- Existing530 refusal/no rephrase/provider switch,539 and619 exhausted attempt
  histories,606/KS and unrelated pauses are untouched. No second delivery owner,
  publisher, supervisor, recurring job, global config or Goal-budget change.
