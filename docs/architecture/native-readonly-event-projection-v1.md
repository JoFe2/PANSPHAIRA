## Snapshot before delta, integrity and bounds

A native authenticated snapshot issues an owner-sealed, principal/epoch/sequence/unit/expiry-bound ephemeral read grant. Before the browser presents that snapshot, a separate native delta read returns the owner's stored `authorizedSnapshotDigest`. This confirms actual owner-issued snapshot bytes rather than treating a caller's matching byte/hash pair as authority. Deltas require that exact grant, epoch, COUNT unit and a valid non-regressing cursor. No-snapshot, wrong/foreign/expired grant, epoch/unit/cursor drift, model/send overrides and additional fields fail closed.

The fixed limits are 128 replay events, 16 samples, 64 live ephemeral grants, 65536 snapshot bytes and a 5000 ms read-grant lease. The producer's original 4096-event bound and all prior product deadlines remain unchanged. Source windows explicitly label truncated history. Bounded bucket selection preserves original minima/maxima and UNKNOWN/STALE/quality boundaries, not averages. If boundaries cannot fit, the response is UNKNOWN plus an explicit gap and RESYNC_REQUIRED, rather than a smoothed current value. Signed stream gaps are hard denials. Every declared downsampling range remains visible for as long as its incomplete table survives, including unchanged deltas; only a new owner-confirmed full snapshot or explicit cache clear resets that history metadata.
